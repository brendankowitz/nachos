---
title: Sessions and messages
---

The source MVP stores sessions, membership and messages with both the in-memory
and SQL providers.

A session groups an interaction and its peer membership. Messages carry the
conversation content within that session. The design separates message order
from timestamps: server-assigned sequence numbers determine ordering, while
timestamps may describe earlier events.

Membership configuration governs which peers participate and how later memory
processing interprets their activity. A stored message is not itself a derived
conclusion, summary, or evidence that a worker has finished processing.

Conclusions are formed from messages in the background; see
[Memory formation](/nachos/concepts/memory-formation/). Messages are found again with
[search](/nachos/concepts/search/), and a session's rolling summaries and token-budgeted
context are described in [Session context](/nachos/concepts/session-context/). Deleting a
session is accepted at once and finished by a background job; see
[Delete sessions and workspaces](/nachos/guides/delete-data/). Dialectic chat is outside
the current build; see the [design and roadmap](/nachos/architecture/) rather than inferring
capabilities from the documentation navigation.
