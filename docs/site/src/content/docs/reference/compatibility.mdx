This page compares the actual build-generated Nachos OpenAPI with the pinned
Honcho wire manifest. It does **not** establish runtime availability, authentication
availability or SDK conformance. Missing means absent from OpenAPI, not necessarily
unmapped by the server.

<p>Wire version: <code>{coverage.wireVersion}</code>.
 SDK conformance: <strong>{coverage.sdkConformance}</strong>.
 Authentication: <strong>{coverage.authentication}</strong>.</p>

  <thead><tr><th>Declaration category</th><th>Count</th></tr></thead>

</table>

`declared-implemented` means 2xx without 501 in the declaration;
`declared-partial` includes both 2xx and 501; `staged-501` is not implemented.
Extension counts overlap these statuses. Jobs and admin grants are Nachos
extensions, not proof of upstream SDK compatibility.
