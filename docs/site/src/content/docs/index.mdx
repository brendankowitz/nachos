## A foundation you can inspect

Nachos is an early, clean-room reference implementation for agent memory.
The source MVP includes workspace, peer, session, membership and message operations,
NachosKey/Entra authentication, a .NET client, in-memory and SQL providers.
This documentation covers the current source and references generated from the
actual API, CLI and option types before each site build.
It is **not** a released memory service, SDK, or deployment package.
Start with the [introduction](/nachos/getting-started/introduction/).
Ready to try it? Follow the [local source quick start](/nachos/getting-started/quick-start/).
